# 🌐 ВІТРИНА ОНЛАЙН — без GitHub Actions і без очікування

## Проблема
GitHub Actions за розписом `*/10` фактично запускався рідко:
за годину був лише один запуск. Через це нові аромати не з'являлись
по 20–40 хвилин, хоча в таблиці все було.

## Рішення
Apps Script віддає каталог як JSON, сайт бере його напряму.
Ніяких черг, комітів і затримок: змінив у таблиці → оновив сторінку → вже є.

## Установка (один раз, 3 хвилини)

1. Apps Script: вставити новий `Код.gs` → Ctrl+S.
2. **Deploy → New deployment** (або керувати розгортаннями).
3. Тип: **Web app**.
   - Description: `catalog`
   - Execute as: **Me**
   - Who has access: **Anyone**
4. Deploy → скопіювати **Web app URL** (закінчується на `/exec`).
5. Перевірка в браузері: додай до URL `?api=1`
   ```
   https://script.google.com/macros/s/AKfy.../exec?api=1
   ```
   Має відкритись JSON: `{"ok":true,"count":558,"products":[...]}`
6. Пришли мені цей URL — впишу в сайт.

## Що це змінює

| Було | Стало |
|---|---|
| ціни через GitHub Action раз на 10+ хв | одразу з таблиці |
| треба чекати після додавання | оновив сторінку — вже є |
| помилка в Action → сайт старий | дані завжди з таблиці |

`data.json` лишається як запасний варіант: якщо Apps Script недоступний,
сайт покаже останній збережений знімок.

## Важливо

- Публікація листів у CSV більше не потрібна для роботи сайту.
  (Можна лишити, не заважає.)
- Доступ «Anyone» означає, що JSON може відкрити будь-хто, хто знає посилання.
  Там тільки бренд, аромат, ціна, стать, тип, опис, Telegram, фото.
  Собівартість і закупівля **не** віддаються.

## Перевірка

- [ ] Посилання `?api=1` відкриває JSON.
- [ ] На сайті у правому верхньому куті біля кількості написано «Онлайн».
- [ ] Додав аромат у таблицю → оновив сторінку → він на місці.
