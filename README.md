# Freshdoze — тимчасова вітрина

Статичний сайт для GitHub Pages. Ціни беруться з Google Таблиці, фото й описи — з Google Документа (перенесені один раз).

```
Товари (CRM)
   ↓ формули
лист «Вітрина»  →  опублікований CSV
   ↓ GitHub Action (раз на 10 хв)
 data.json  →  сайт
```

## Що де лежить

| Файл | Призначення |
|---|---|
| `index.html`, `styles.css`, `app.js` | сам сайт |
| `data.json` | позиції: бренд, аромат, ціна за мл |
| `content.json` | описи, категорії, посилання Telegram, шляхи до фото |
| `images/` | фото з Google Документа |
| `scripts/update.mjs` | оновлення `data.json` з CSV |
| `scripts/parse_doc.py`, `scripts/build_content.py` | одноразовий імпорт з Google Документа |
| `.github/workflows/update.yml` | запуск оновлення за розкладом |

## Встановлення

### 1. Google Таблиця

1. У CRM: меню `⭐ CRM → 📊 Звіти → 🛍 Оновити лист «Вітрина»`.
2. Відкрий `Файл → Поділитися → Опублікувати в інтернеті`.
3. Зверху вибери **аркуш «Вітрина»**, не «Уся книга».
4. Формат: **CSV** → `Опублікувати` → скопіюй посилання.

> Публікується лише «Вітрина»: бренд, аромат, ціна ОЛХ, наявність.
> Собівартість, залишки в мл і коментарі в публічний файл не потрапляють.

### 2. GitHub

1. `github.com` → **New repository** → `freshdoze-showcase` → **Public** → Create.
2. **Add file → Upload files** → перетягни все, крім `.git`.
3. **Settings → Pages** → Source: `Deploy from a branch` → `main` / `/ (root)` → Save.
4. Через хвилину сайт: `https://ТВОЙ_ЛОГІН.github.io/freshdoze-showcase/`.

### 3. Автооновлення

1. **Settings → Secrets and variables → Actions → Variables → New repository variable**
   - Name: `SHEET_CSV_URL`
   - Value: посилання з кроку 1.
2. Вкладка **Actions** → увімкнути workflows.
3. Перевірка: **Actions → Update prices from Google Sheets → Run workflow**.

Раз на 10 хвилин Action читає CSV і комітить новий `data.json`, якщо ціни змінилися.

## Як додати новий аромат

1. У `Товари` додай рядок: бренд, аромат, залишок, ціна ОЛХ.
2. Якщо є фото — поклади файл у `images/` і додай запис у `content.json`
   (`byName`: ключ — назва у нижньому регістрі без зайвих символів).
   Без фото покажеться заглушка.
3. Через 10 хвилин позиція на сайті.

## Ціни

- Позиція: `ціна за 1 мл` з колонки «Ціна ОЛХ за мл».
- Варіанти 2/3/5/10/15/20/30/50 мл рахуються як `ціна × обʼєм + флакон`:
  `2—20, 3—25, 5—25, 10—30, 15—40, 20—50, 30—60, 50—70`.
- Наявність = 0 → позиція не показується.

## Локальний запуск

```bash
python3 -m http.server 8080
```

Відкрий `http://localhost:8080/`. Через `file://` не працює — `fetch` блокується.

## Замовлення

Кошик зберігається в `localStorage`. Кнопки:
- **Скопіювати замовлення** — текст у буфер;
- **Замовити в Telegram** — `t.me/AndresBurmachenko` з текстом;
- **Замовити у Viber** — копіює текст і відкриває Viber.
